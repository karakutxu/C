Build
gcc -O2 proto_demo.c -o proto_demo
Setup
sudo bash setup_demo.sh

Terminal 1 — receiver
sudo ip netns exec nsB bash

Get MAC:

ip link show vethB

Example:

8e:11:22:33:44:55

Start receiver:

./proto_demo rx tun0 vethB dummy

Terminal 2 — sender
sudo ip netns exec nsA bash

Run sender:

./proto_demo tx tun0 vethA 8e:11:22:33:44:55

Terminal 3 (sudo ip netns exec nsA bash) — generate traffic

Inside nsA:

ping 10.20.0.1
Expected output

Sender:

TX: 10.10.0.1 -> 10.20.0.1 len=84

Receiver:

RX: 10.10.0.1 -> 10.20.0.1 len=84

Ping succeeds.
